===========================================================
IHealDrunk Media
Version 3.8.0
===========================================================

Thank you for downloading IHealDrunk Media!

IHealDrunk Media is a collection of custom fonts, statusbars,
sounds, Details! textures, and icons for World of Warcraft.

The addon registers all included media with
LibSharedMedia-3.0, making it available to any addon that
supports LibSharedMedia.

Compatible addons include (but are not limited to):

 • ElvUI
 • WeakAuras
 • Details!
 • Plater
 • BigWigs
 • Deadly Boss Mods (DBM)
 • Shadowed Unit Frames
 • Cell
 • Any addon that supports LibSharedMedia


===========================================================
INSTALLATION
===========================================================

1. Close World of Warcraft.

2. Extract the folder:

   IHealDrunk_Media

3. Copy the folder into:

   World of Warcraft
      └─ _retail_
          └─ Interface
              └─ AddOns

4. Launch World of Warcraft.

5. Enable "IHealDrunk Media" from the AddOns menu.


===========================================================
USAGE
===========================================================

Once loaded, all included media is automatically registered
with LibSharedMedia.

Fonts, textures, sounds, icons, and Details! artwork will
appear in supported addons without any additional setup.

Simply open the configuration for your preferred addon and
select the media from the available lists.

===========================================================
ADDING YOUR OWN MEDIA
===========================================================

Advanced users may add their own media.

1. Copy your files into the appropriate folder.

   Fonts
   Statusbar
   Sounds
   Details
   Icons

2. Run:

   update_media.bat

3. The addon will automatically rebuild:

   IHealDrunk_Media.lua

No manual Lua editing is required.


===========================================================
TROUBLESHOOTING
===========================================================

Media does not appear:

• Verify the addon is enabled.

• Verify another addon using LibSharedMedia is installed.

• Restart the game after making changes.

• Run update_media.bat if new media has been added.

• Check that filenames do not contain unsupported characters.


===========================================================
DEVELOPERS
===========================================================

This project automatically generates
IHealDrunk_Media.lua using update_media.bat.

The generated Lua file should not be edited manually.

To add or remove media:

 • Add or remove files from the appropriate folders.
 • Run update_media.bat.
 • Commit the updated Lua file.
