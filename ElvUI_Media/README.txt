==================================================
              ElvUI MaMedia Addon
==================================================

Thank you for downloading this custom media package!

This addon adds additional Fonts, Statusbar Textures,
Sounds, Details textures, and Icons for use inside
ElvUI, WeakAuras, Details!, Plater, and other addons
that use LibSharedMedia.

This addon is intended for personal and community use
and contains a mix of custom-made assets and community
media.

--------------------------------------------------
 1. HOW TO INSTALL
--------------------------------------------------

1. Unzip the downloaded folder.
2. Place the folder named:

   ElvUI_Media

   into your World of Warcraft AddOns directory:

   World of Warcraft\_retail_\Interface\AddOns\

Your folder structure should look like:

   Interface\AddOns\ElvUI_Media\

3. Launch World of Warcraft and ensure the addon is
   enabled on the character selection screen.
4. If already in-game, type:

   /reload

--------------------------------------------------
 2. HOW TO UPDATE MEDIA FILES
--------------------------------------------------

All fonts, textures, sounds, and icons must be placed
inside their respective subfolders:

   Fonts
   Statusbar
   Sounds
   Details
   Icons

After adding or removing any media files, RUN:

   update_media.bat

This batch file automatically rebuilds:

   ElvUI_Media.lua

which registers all media files with LibSharedMedia.

IMPORTANT:
• You do NOT need to manually edit ElvUI_Media.lua
• The file is fully generated by the batch script

--------------------------------------------------
 3. HOW TO USE IN-GAME
--------------------------------------------------

ELVUI:
   Go to:
      ElvUI → General → Media
   or any font / texture dropdown within ElvUI.

WEAKAURAS:
   When selecting fonts or textures, search for the
   filename (without the file extension).

DETAILS!:
   Options → Bars → Texture
   Options → Skins → Panel Texture

PLATER:
   Fonts, textures, and icons will appear automatically
   in the available media lists.

--------------------------------------------------
 4. TROUBLESHOOTING
--------------------------------------------------

• Media does not appear in-game:
    - Did you run update_media.bat?
    - Are the files in the correct subfolder?
    - Did you /reload or restart the game?

• Lua errors or missing media:
    - Confirm ElvUI_Media.lua exists
    - Ensure update_media.bat completed successfully
    - Avoid special characters in filenames
    - Make sure ElvUI and LibSharedMedia are installed

--------------------------------------------------
 5. IMPORTANT NOTES
--------------------------------------------------

• This addon requires:
     LibSharedMedia-3.0
  (Already included with ElvUI)

• This addon does NOT modify your UI by itself.
  It only provides additional media options for
  other addons to use.
