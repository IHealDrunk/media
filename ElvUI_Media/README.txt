=========================================================
                  ElvUI Media
=========================================================

Thank you for downloading ElvUI Media!

This addon provides additional:

 • Fonts
 • Statusbar Textures
 • Sounds
 • Details! Textures
 • Icons

for ElvUI and any addon that supports LibSharedMedia.

=========================================================
1. INSTALLATION
=========================================================

1. Extract the ZIP file.

2. Copy the folder:

      ElvUI_Media

   into:

      World of Warcraft
      └── _retail_
          └── Interface
              └── AddOns

3. Launch World of Warcraft.

4. Make sure ElvUI_Media is enabled.

5. If already in-game, type:

      /reload

=========================================================
2. ADDING NEW MEDIA
=========================================================

Place your files into one of the following folders:

   Fonts
   Statusbar
   Sounds
   Details
   Icons

Then run:

   update_media.bat

The batch file automatically rebuilds:

   ElvUI_Media.lua

IMPORTANT

Do NOT manually edit ElvUI_Media.lua.

It is completely generated by update_media.bat.

=========================================================
3. USING THE MEDIA
=========================================================

ELVUI

General → Media

or any Font / Texture selection.

WEAKAURAS

Fonts and textures will automatically appear.

DETAILS!

Options

→ Bars
→ Textures

PLATER

Fonts, textures and icons automatically become available.

=========================================================
4. TROUBLESHOOTING
=========================================================

Media missing?

• Verify ElvUI_Media is enabled.
• Verify ElvUI is installed.
• Run update_media.bat.
• Type /reload.
• Make sure folders are not nested.

=========================================================
5. REQUIREMENTS
=========================================================

Required:

 • ElvUI
 • LibSharedMedia-3.0

(LibSharedMedia is already included with ElvUI.)

=========================================================
6. ABOUT
=========================================================

This addon does not modify your UI.

It simply registers additional media that other addons
can use.

Included assets consist of:

 • Original custom-created media
 • Community-created media
